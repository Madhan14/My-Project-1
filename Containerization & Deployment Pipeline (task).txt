# Use Nginx to serve static files
FROM nginx:alpine

# Remove default nginx static assets
RUN rm -rf /usr/share/nginx/html/*

# Copy your static site files into nginx html folder
COPY . /usr/share/nginx/html

# Expose port 80
EXPOSE 80

# Start nginx
CMD ["nginx", "-g", "daemon off;"]

🔹 Step 3: Push Image to AWS ECR

Create an ECR repo in AWS console (e.g., my-static-website).



Authenticate Docker with ECR:
------------------------------------------

->  sudo aws ecr get-login-password --region <your-region> | docker login --username AWS --password-stdin <account_id>.dkr.ecr.<your-region>.amazonaws.com


->  sudo aws ecr create-repository --repository-name my-static-website --region ap-south-1


Tag the image for ECR:
--------------------------------

-> sudo docker tag my-static-website:latest <account_id>.dkr.ecr.<your-region>.amazonaws.com/my-static-website:latest



Now Push it to the ECR Repo...
-----------------------------------------

->  sudo docker push <account_id>.dkr.ecr.<your-region>.amazonaws.com/my-static-website:latest



Now we have to Pull your image from ECR:
---------------------------------------------------------

->  sudo  docker pull <account_id>.dkr.ecr.<your-region>.amazonaws.com/my-static-website:latest


Run the container:
-------------------------

->  sudo docker run -d -p 8080:80 <account_id>.dkr.ecr.<your-region>.amazonaws.com/my-static-website:latest



Now we can copy the Public IP and attach with exposed port to hit the browser to check whether it's working or not...
